## 🧑‍💻 About Me

I'm a passionate game developer from Guadalajara, Mexico, currently studying Videogame Development Engineering.

I enjoy bringing ideas to life through code, designing gameplay mechanics, and creating interactive experiences that connect with players.

My main interests include gameplay programming, game systems, interactive storytelling, and immersive world-building.

- 🔭 **Currently working on:** [Mana Zone](https://blackcreatorx.itch.io/manazone)
- 🌱 **Currently learning:** Unreal Engine 5, C++ and advanced gameplay programming.
- 🎯 **Interested in:** Gameplay Engineering, Game AI, and Narrative-Driven Experiences.
- 🤝 **Open to collaborating on:** Indie games, game jams, and creative interactive projects.
- 💬 **Ask me about:** Unity, C#, gameplay systems, game mechanics, and game development.
- 🚀 **Long-term goal:** Contribute to ambitious games and work alongside talented developers in the industry.

## 🎮 Featured Projects

### ✨ Mana Zone
**A tactical magic dueling experience.**

A PC game prototype inspired by magical dueling, featuring tactical spellcasting, resource management, enemy encounters, and roguelike progression.

[![Play on itch.io](https://img.shields.io/badge/Play%20on-itch.io-fa5c5c?style=for-the-badge&logo=itchdotio&logoColor=white)](https://blackcreatorx.itch.io/manazone)

### 🐈 Can Someone Save My Kitties
**Save the kitties. Break the city.**

An arcade driving experience developed during a game jam. Race against time, rescue cats, and deliver them to safety.

🏆 2nd Place — UNiAT Game Jam 2026.

### 🃏 The Wildcard
**Survive. Adapt. Keep moving.**

A survival bullet-hell project inspired by roguelite action games, focused on combat systems, player progression, and fast-paced gameplay.
